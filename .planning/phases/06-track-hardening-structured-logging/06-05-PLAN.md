<objective>
Insert size-only os.Stat input validation at the single FFmpeg-invocation seam (MergeEverything) so a zero-byte input track can never produce a positional -map mislabeling. Deliverable for ERR-04.

Purpose: The root cause of the positional -map mislabeling bug is FFmpeg receiving zero-byte (or absent) tracks, which shifts all subsequent -map indices. Validating inputs before args are assembled (D-10/D-12) prevents it at the single point that invokes FFmpeg.

Output: Modified internal/mux/mux.go and extended internal/mux/mux_test.go.
</objective>
